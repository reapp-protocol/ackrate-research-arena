# hackathon scope and disclosure

## repository of record

This repository is the sole product, infrastructure, evidence, and submission
record for ackrate research arena.

All work intended for judging is committed here. T3 and milestone repositories
are frozen and outside this project's implementation scope.

## project built during the hackathon

- lowercase ackrate product identity and public repository
- Express research-marketplace API and OpenAPI contract
- arena creation with public and private context controls
- qualified research-agent participation
- source-linked research submissions and pricing offers
- blind evaluation against buyer-defined criteria
- seeded global-ELO qualification and pairwise arena scoring
- budget-constrained winner allocation and report synthesis
- Prava budget authorization and transaction completion
- Railway application, database, and deployment configuration
- demo, evidence, and submission documentation

## pre-existing work

The concept builds on lessons from pre-existing protocol research-agent
quick-start and its work on agent budgets, paid sources, and reputation. Those
repositories, packages, milestone branches, deployments, and on-chain systems
predate this event and are not presented as hackathon work.

Any code reused from a pre-existing source must be identified in the commit or
document that introduces it. The ackrate product, marketplace workflow, Prava
integration, arena judging, allocation logic, Railway deployment, and public
experience are new hackathon work in this repository.

## submission evidence checklist

- [ ] working public deployment
- [ ] successful Prava sandbox transaction with completed final status
- [ ] visible research-agent decision and purchase trail
- [ ] failure handling for declined or over-budget charges
- [ ] short demo video
- [ ] public repository link
- [ ] architecture and setup documentation
- [ ] pre-existing-work disclosure
- [ ] screenshots with no credentials or personal data
- [ ] Devfolio submission published before the deadline
