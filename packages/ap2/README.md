# @ackrate/ap2

Fail-closed AP2 mandate validation and binding for ackrate payments on Stellar.

```bash
npm install @ackrate/ap2 @ackrate/core
```

Legacy `reapp-*` binding values and the signing domain are intentionally frozen
wire identifiers. They remain unchanged so signed credentials and deployed
contracts stay interoperable; they are not the package or product brand.
